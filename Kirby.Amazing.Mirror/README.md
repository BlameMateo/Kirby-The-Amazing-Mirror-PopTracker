# Kirby & The Amazing Mirror PopTracker Pack

This a Kirby & The Amazing Mirror tracker package for PopTracker. This tracker supports the Archipelago version of the Randomizer.

## Installation

Just download the latest release and put it in your packs folder.

## Bugs & Feedback

Feel free to post any issues you find on Github, or ask any questions in the Kirby & The Amazing Mirror thread on the Archipelago Discord!
